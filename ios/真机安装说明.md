# 街坊行 · 装到自己的 iPhone

用你自己的 Mac 和 Apple ID（免费的就行）把「街坊行」装到 iPhone 上测试。

## 要准备
- 一台 Mac，系统要新到能从 App Store 装最新版 Xcode
- 一台 iPhone，iOS 18 以上；碰一碰要 iPhone 11 或之后的机型，旧机型改用二维码
- 一条能传数据的线（有些线只能充电）
- 一个 Apple ID

## 第一次安装（主要时间花在下载 Xcode，约 30–60 分钟）
1. 在 Mac 的 App Store 装 **Xcode**，装好后打开一次，按提示装完组件（勾 iOS）。
2. Xcode 菜单 → **设置（Settings）→ Apple 账户（Apple Accounts）** → 左下角 **+** → 登录你的 Apple ID。
3. 把收到的 `StreetWalk_install.zip` 放进「下载」文件夹，双击解压，得到 `StreetWalk` 文件夹。
4. iPhone 用数据线插上 Mac，**解锁手机**。手机问「要信任这台电脑吗？」→ 按「信任」，输入锁屏密码。Mac 问「允许配件连接？」→ 按「允许」。
5. 打开 Mac 的「**终端**」（启动台里搜「终端」），粘贴下面这行，按回车：
   ```
   cd ~/Downloads/StreetWalk && zsh tools/install_device.sh
   ```
6. 按终端里的提示做，做完再粘贴第 5 步那行重跑一次：
   - **开发者模式**：手机 设置 → 隐私与安全性 → 拉到最底「开发者模式」→ 打开 → 重新启动；重启解锁后按「打开」。
   - **信任开发者**（装好后第一次）：手机 设置 → 通用 → VPN 与设备管理 → 点开发者那一栏 → 信任。
   - 手机系统很新时，Mac 会弹出「正在下载」，等它下完再重跑。
7. 看到「已安装并打开」就好了。

## 以后
- 免费 Apple ID 装的 App **7 天后会打不开**：插上线，重跑第 5 步那行就行，资料不会丢。

## 打开 App 后
- 取一个网名。定位选「**始终允许**」（要认出哪里是家、出门时自动记录），通知选允许；碰一碰时允许「附近互动」和「本地网络」。
- 界面默认是粤语繁体，在设定 →「語言 / 语言」可以换成普通话简体。
- **碰一碰加街坊**：两台都打开 App →「街坊」页 → 碰一碰 → 两部手机贴近（约 20 厘米内）停一下。
- **找人**：成为街坊后，在「街坊」页点对方 →「過去搵佢」，看箭头和距离。
- **出门提醒**：App 要先在家过一晚才认得哪里是家，第二天出门时才会提醒街坊。
- 排行榜只显示住在你家附近的人。
- 语音用手机自带的声音。
