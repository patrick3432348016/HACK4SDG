# Private voice-service configuration

This directory contains member B's Doubao configuration for internal testing in the private repository.

The voice key, Ark key, model, and speaker settings came from `VoiceAssistant-Mac Private/voice-config.json`. On 12 October 2026, the user authorized keeping the configuration in this **private repository** for team testing.

Do not make the repository public or share the configuration outside the authorized team. Usage is charged to the configured provider account.

Startup prefers the external runtime configuration when present; otherwise it uses the repository configuration. Rotate keys through the provider console when necessary. This README describes configuration handling; it does not reproduce any key.
